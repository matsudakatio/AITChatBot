1. 学籍年限・修業年限・在学年限・休学年限
・学部: 標準修業年限4年、在学年限8年、休学年限3年 
・大学院・前期課程: 標準修業年限4年、在学年限2年、休学年限2年 
・大学院・後期課程: 標準修業年限3年、在学年限6年、休学年限3年 
・休学期間は在学年数に算入されません 。  休学・復学・退学等 
・休学: 疾病その他やむを得ない事情で2ヶ月以上修学できない場合、願い出て休学できます 。原則として学期単位（前期: 4/1～9/30、後期: 10/1～3/31）で、期間は1年以内です 。
・復学: 休学事由が終わった時は願い出て復学できます 。原則として学期単位（前期: 4/1、後期: 10/1）です 。
・退学: 学業を続ける見込みがないときに願い出て退学できます 。退学の月の属する学期の授業料等は納めなくてはなりません 。
・除籍: 在学年限を超えた場合、休学期間が終わり復学を願い出ない場合、授業料等の納付を怠った場合などに除籍となります 。

転学部・転学科・転専攻: 希望先が受入れ可能で、資格・要件を満たしている場合に考査のうえ認められることがあります 。
・他大学への転学: 大学の許可が必要です 。
・入学前既修得単位の認定: 他の大学または短期大学を卒業・中途退学した者が本学第1年次に入学した場合、審議のうえ合計30単位まで本学の単位として認められることがあります 。

2. 学費
授業料等学納金 内訳（2025年度入学生） 
・入学金、授業料、教育研究充実費、学友会費、各種保険料、後援会費などが含まれます 。
・工学部（4年間合計）: 入学手続時969,010円、2年次以降の学費を含めた4年間合計は詳細な表で示されています 。
・経営学部・情報科学部: ノートパソコン購入費（自己負担金 28,000円）と設定費・保守費（32,000円）が入学手続時に加算されます 。
・納入期限: 前期分は5月6日、後期分は10月6日です（土日祝日の場合は繰下げ） 。
・納入方法: 原則として口座振替方式です 。
・納入の猶予措置: 経済的理由などにより納入が困難な場合、申請により猶予が認められることがあります（前期分猶予期限：6月30日、後期分猶予期限：11月30日） 。

3. 奨学金・貸費金・助成制度等
愛知工業大学独自の給付奨学金: 選抜奨学生（授業料相当額の50%）、成績優秀奨学生（月額50,000円）、瑞若会奨学生（年額100,000円）、大学院の優秀者奨学生、後藤すゞ子先生奨学金（学資負担者の死亡等による）があります 。
日本学生支援機構奨学金（JASSO）
・貸与型奨学金: 第一種（無利子）と第二種（有利子）があり、学部生・大学院生が対象で、返還義務があります 。申込基準（学力・家計）の目安が示されています 。
・給付型奨学金: 国の高等教育における修学支援新制度の一つで、原則返還義務がありません（大学院生は対象外） 。区分（第I～第Ⅲ）と通学形態に応じた月額が定められています 。
文部科学省 授業料等減免制度: 修学支援新制度の一つで、入学金や授業料の減免が行われます 。減免額は区分（第I～第Ⅲ）により異なります 。申込基準は給付型奨学金と同一です 。
国の教育ローン: 日本政策金融公庫が提供する教育資金の融資制度です 。
大学提携教育ローン: オリエントコーポレーションやジャックスと提携した教育ローン制度があり、「愛知工業大学提携教育ローン利子補給制度」が利用できます 。
・助成制度: 瑞若会学生助成金（上限3万円、学会発表の交通費・宿泊費など）があります 。
・A・SA制度: 教育活動の充実や学生生活の改善を目的として、大学院生をTA（教育補助）に、学部生・大学院生をSA（授業補助など）に採用しています 。

4. 学生生活上の各手続
住所変更等: 学生本人の住所・連絡先はL-Cam（PC版）の学事システムから変更可能です 。保証人情報に変更があった場合は各窓口に届け出てください 。
・拾得物・遺失物: 学内で忘れ物・落とし物や見つけた物があった場合は、各窓口に届けてください 。保管期間は原則3ヶ月間（貴重品類は原則1年間）です 。
・盗難: 学内で盗難にあった場合は、各窓口へ届け出るとともに最寄りの警察署・交番へ届け出てください 。

通学手段 
・八草キャンパス: 自動車（〇）、バイク（〇 ※登録必要 ）、自転車（〇 ※登録不要 ） 。構内への自動車・バイク・電動キックボードの乗り入れは原則禁止です 。
・自由ヶ丘キャンパス: 自動車（×）、バイク（×）、自転車（〇 ※登録不要 ）、電動キックボード（×） 。
・自転車通学者は「自転車損害賠償責任保険等」への加入が義務化されています 。
通学定期券: 学生証と本学発行の「在籍確認兼通学証明書シール」が必要です 。
学校学生生徒旅客運賃割引証（学割証）: 修学上の経済的負担軽減を目的として発行されます 。有効期限は発行日から3ヶ月で、1回につき4枚発行できます 。不正使用は厳禁です 。
学生の団体旅行割引: 学生8名以上で引率者が同行する団体旅行に利用できます 。
下宿・アパートの紹介: 株式会社エイアイテック（メディアショップ Com・Com）に業務委託しています 。
国民年金保険料学生納付特例制度: 20歳以上の学生は、大学を通じて申請できます 。

3. 学生証
学生証は本学の学生として身分を証明するものです 。
1. 学生証は常時携帯し、教職員から要求があった場合はいつでも提示できるようにしてください 。
2. 紛失、盗難などのないよう取扱いには十分注意してください 。
3. 学生証を他人に貸与又は譲渡することを禁じます 。
4. 学生証の携帯がない場合は試験を受けることができません 。
5. 紛失、破損、汚損した場合は再発行手続きをしてください（再発行手数料1,000円） 。
6. 記載事項に変更が生じた場合は大学に申し出てください 。
7. 有効期限が過ぎた場合又は学籍を離れた場合は、直ちに大学へ返還してください 。
