情報科学科

情報科学部情報科学科 卒業認定・学位授与の方針 (ディプロマ・ポリシー)
情報化社会において、情報・コンピュータ・メディアに関する基礎知識 、システム設計や安全性確保のための技術・技能を備え 、情報技術を応用できる技術者が求められています 。学士（情報科学）には、「創造と人間性」をモットーに培われた幅広い教養を礎に 、情報科学の基礎知識・技術・技能を修得し、社会に役立てることのできる高度な専門技術者として、以下の能力・資質が求められます 。
1. 人間科学・社会科学・語学に関する深い知識を持ち、それらの知識を関連づけることで、日常に潜む課題を明らかにできる能力 。
2. 自然科学の知識を修得し、課題に対する論理的・科学的な思考や分析ができる能力 。
3. 情報技術の基礎的および専門的な知識を持ち、その知識をどのように適用すれば課題が解決できるかを考え、提案できる能力 。
4. コンピュータシステム分野の技術（システム開発手法など）やメディア情報分野の技術（コンテンツ制作手法など）を、課題解決に実践的に応用できる能力 。
5. 情報システムの研究経験やメディア・コンテンツの制作経験を活かして、産業および社会が求めるより高度な課題に対しても、解決策を見いだせる能力 。
6. 身につけた専門知識・技術・経験を健全な情報化社会の発展に役立てるための、深い教養と高い倫理性 。
情報科学部情報科学科 教育課程編成・実施の方針 (カリキュラム・ポリシー)
学位授与の方針（ディプロマ・ポリシー）に掲げた能力・資質を持つ人材を育成するため 、情報科学科では、以下の教育課程を編成・実施します 。

コンピュータシステム専攻 (KK): 情報技術者を養成するための様々なコンピュータシステムの開発能力の育成を目的とした教育課程 。
メディア情報専攻 (KX): メディア・クリエイターを養成するための様々な情報コンテンツの開発能力の育成を目的とした教育課程 。
それぞれの教育課程において、以下の方針に沿ったカリキュラムを編成します。
1. 日常に潜む課題を自ら見つけられる発想力を身につけるべく、人間・社会・言語に関する知識を学ぶための授業科目を配する 。
2. 見つけた課題に対する論理的・科学的な思考力や分析力を身につけるべく、自然科学の知識を修得するための授業科目を配する 。
3. 課題の解決法提案に必要な情報技術の知識を身につけるべく、コンピュータシステムの知識や、種々のメディアを用いたコンテンツの知識を修得するための授業科目を配する 。
4. 課題解決のための実践的な技術を身につけるべく、種々のシステムの開発手法やコンテンツの開発手法を学ぶための演習系の授業科目を配する 。
5. 社会が求めるより高度な課題に対しても解決策を見いだせる十分な能力を身につけるべく、情報システムの研究経験やメディア・コンテンツの制作経験を得るための卒業研究・卒業制作の科目を配する 。
6. 深い教養と高い倫理性を備えた社会人となるべく、キャリア形成に必要な知識や体験を得るための授業科目を配する 。

コンピュータシステム専攻 (KK) の卒業・進級要件と履修上の注意
卒業要件単位数
| 科目区分 | 専門教育科目 | 総合教育科目 | 計 |
|----------|----------------|----------------|------|
| 必修科目 | 32単位 | 8単位 | 40単位 |
| 選択科目 | 68単位以上 | 16単位以上 | 84単位以上 |
| 合計 | 100単位以上 | 24単位以上 | 124単位以上 |


・総合教育科目必修8単位の内訳は、必修科目3単位と選択必修科目5単位の合計です 。このうち、英語系科目を6単位以上修得している必要があります 。
・選択必修科目（※2印の授業科目）から1科目（3単位）を必修として選択して修得する必要があります 。2科目目以降は選択科目に加算されます 。
卒業および進級要件に含めない科目
・高大連携特別講義は、進級判定時の単位数には含めず、卒業要件単位数にのみ加算します 。
・日本語コミュニケーションで修得した単位は、卒業・進級要件に含めません 。
履修上の注意 (KK専攻)
・科目系統の理解: 各科目は密接に関連しており 、高学年の科目を理解するためには、前提となる科目を低学年で修得しておく必要があります 。カリキュラムツリーを理解し、各学年に割り当てられた科目を大切に履修してください 。
・キャリアデザインⅠ: 大学生活の充実と将来の社会での活躍のために、大学で何を学ぶべきかを考える授業であり 、積極的に参加して将来計画を作成するよう推奨されています 。
必修・選択必修科目: 卒業にはこれら全ての修得が必要であり、不合格になると再履修が必要になりますが、在籍学年の科目と開講時間が重なるなど、容易ではないため、割り当てられた学年で必ず合格するよう努めてください 。
GPA: 履修科目をしっかり身につけるため、GPAは2.0以上を目指すことが推奨されています 。
演習科目: 将来の仕事と直接関係し、実践力を養うため、できるだけ多く、積極的に履修してください 。ただし、一部の演習科目には履修条件があります 。
例: プロジェクト演習Ⅰ、Ⅱは1年次のGPAが2.5以上が履修条件です 。
数学・物理科目: コンピュータやソフトウェアの科目を理解するために必要であり、就職後リーダー・管理者となった際にも重要であるため、積極的に履修し、基礎学力向上に努めることが推奨されています 。
 修学

1. 教育課程表の見方
(1) 単位制と教育課程表
・各専攻の授業科目の種類、単位数、開講期、および卒業・進級要件は、『教育課程表』（カリキュラムとも呼ぶ）に記載されています 。
・すべての授業科目には所定の単位が配当されており、授業を履修し、試験などに合格することによって、その科目の単位を修得することができます 。
・各年次に1年以上、通算4年以上在学し、卒業要件に定められた単位を修得した者は、卒業となります 。
・各専攻の「科目系統図」には、卒業までに身につけるべき知識と、これを得るための授業関連性が記載されています 。
(2) 目的による科目の分類
授業科目は、その目的により以下のように分類され、それぞれ教育課程表で定められた単位を修得しなければなりません 。
| 科目分類 | 目的 |
|----------|--------|
| 専門教育科目 | 専門的な知識・技能を身につけるための科目 |
| 総合教育科目 | 一般教養を身につけるための科目 |
| 教職課程科目 | 教員養成のための科目 |
 

(3) 卒業の要件による科目の分類
授業科目は、卒業の要件により以下のように分類されます 。
| 科目分類 | 概要 |
|----------|--------|
| 必修科目 | 卒業に必要な科目で、必ず履修し、単位を修得しなければならない科目 |
| 選択必修科目 | あらかじめ指定された科目群の中から、指定された単位数を修得しなければならない科目 |
| 選択科目 | 自由に選択して履修できる科目 |


(4) 授業科目の開講時期
授業科目の開講時期は以下の通りです 。
| 開講時期 | 授業期間 | 単位認定 |
|----------|-----------|------------|
| 前期 | 4月1日～9月30日（ただし授業は概ね9月上旬まで） | 9月 |
| 後期 | 10月1日～3月31日（ただし授業は概ね1月下旬まで） | 3月 |
| 通年 | 4月1日～3月31日 | 3月 |
| 集中 | 各学期の授業期間外（夏期・冬期休暇期間等） | 9月または3月 |



2. シラバス（授業計画書）・オフィスアワー
シラバス：各授業科目の目的、目標、内容、評価方法、授業計画などが詳細に記載された授業計画書です 。履修登録を行う前に、必ずシラバスで内容を確認してください 。
オフィスアワー：授業時間以外に教員が学生からの質問や相談に対応するために、研究室等で在室する時間帯です 。この時間を利用して、授業の内容や学業全般について教員に相談することができます 。オフィスアワーはシラバスに記載されています 。
3. 履修フローチャート
・履修する授業科目の種類は、基礎から専門へ、また低学年から高学年へと段階的に編成されており、それぞれの科目が有機的に関連しています 。
・教育課程表の履修フローチャートを参照し、自分の学習計画を立ててください 。

(2) 授業形態
・授業は、講義、演習、実験、実習のいずれか、またはこれらを組み合わせて行われます 。
(3) 欠席
・欠席した場合は、出席扱いの扱いを原則としません 。
・ただし、疾病、交通機関の事故、忌引きなどやむを得ない事情で欠席する場合は、欠席理由を証明する書類（診断書、事故証明書、会葬礼状など）を添えて、欠席届を各窓口（教務グループまたは学生サービスグループ）に提出してください 。
・出席扱いの判断は、欠席届と証明書に基づき、各科目担当教員が行います 。
5. 履修登録
・履修登録とは、その学期に履修する科目を確定させる手続きです 。
・この手続きをしないと、たとえ授業に出席していても、その科目の単位は修得できません 。
・履修登録期間は、各学期開始後、L-Camで確認してください 。
・履修登録の取り消しは、原則として認められません 。
・一度に履修登録できる単位数の上限は、原則として年間49単位です 。
6. 試験
(1) 定期試験
・各科目の成績評価は、原則として授業期間終了後の定期試験と平常点（レポート、小テスト、出席など）により総合的に行われます 。
・定期試験の実施期間は、各学期の行事予定表で確認してください 。
・学生証の提示がないと受験できません 。
・携帯電話・スマートフォン、タブレット等の通信機器類は、試験会場に入る前に電源を切り、カバン等にしまってください 。
・不正行為があった場合は、当該科目の成績評価は**不可（F）となり、その他全履修科目の成績評価も不可（F）**となります 。さらに、停学等の懲戒処分を受けます 。
(2) 追試験
・疾病、忌引きなどやむを得ない理由により定期試験を受けられなかった場合、追試験願を提出し、教務グループの承認を得て追試験を受けることができます 。
・追試験願は、試験終了後原則5日以内に提出してください 。
・追試験の成績評価は、原則として合格（C）が上限となります 。
(3) 再試験・再々試験
・定期試験の結果、不合格（F）になった科目は、再試験や再々試験の対象となる場合があります 。
・再試験や再々試験は、原則として合格（C）が上限となります 。
(4) 再チャレンジ履修制度
・不合格（F）になった科目を、その科目がある学期の履修制限単位数を超えて再度履修できる制度です 。
・再チャレンジ履修での成績評価は、原則として合格（C）が上限となります 。
7. 単位認定とGPA
(1) 成績評価
成績は、**秀、優、良、可、不可（F）**の5段階で評価されます 。合格は「秀」～「可」です 。
| 評価 | 評価点 | 単位認定 |
|------|---------|------------|
| 秀 | 100～90点 | 合格 |
| 優 | 89～80点 | 合格 |
| 良 | 79～70点 | 合格 |
| 可 | 69～60点 | 合格 |
| 不可（F） | 59点以下 | 不合格（単位不認定） |


(2) GPA (Grade Point Average) 制度
・GPAは、学生の学修成果を客観的に示す指標であり、単位の修得状況を公正に評価するために導入されています 。
・大学院進学、奨学金の受給、留学、インターンシップへの参加、就職活動など、様々な場面で活用されます 。
| 評価 | Grade Point (GP) |
|------|-------------------|
| 秀   | 4.0               |
| 優   | 3.0               |
| 良   | 2.0               |
| 可   | 1.0               |
| 不可（F） | 0.0           |


GPAの対象外となる科目：
・教職課程科目
・インターンシップ 
・日本語コミュニケーション 
・日本語リテラシ 
・特別講義 


8. 成績発表
(1) 成績通知
・成績は毎学期末にL-Cam上で発表され、保証人宛へ郵送されます 。発表日は行事予定表で確認してください 。
・成績や進級・卒業に関わる内容について、原則電話での問い合わせには対応できません 。
(2) 成績説明申請制度
・成績評価に疑問がある場合は、担当教員から指示がある場合を除き、研究室などを訪問し個別に教員から説明を受けるのではなく、成績説明申請願を提出してください 。
・この制度は、成績評価に対する透明性を高めるためのものであり、成績について教員と交渉する機会ではないことに注意が必要です 。
・申請願には、具体的にどのようなことが疑問なのかを詳細かつ明確に書いてください 。疑問に関する資料があれば添付してもかまいません 。
棄却される申請願の例：「卒業のためにFを合格にしてほしい」「奨学金受給の関係でせめて優評価にしてほしい」といった内容の申請は受け付けません 。
・成績説明申請期間は、行事予定表で確認してください 。
9. 進級・卒業・留年
(1) 進級要件
・各学科・専攻では、円滑に学修が進められるよう、2年次、3年次への進級に要件を設けています 。
・進級要件は、学科・専攻によって異なります。詳細は教育課程表で確認してください 。
・進級要件を満たせない学生は留年となります 。
(2) 卒業要件
・卒業に必要な単位は、124単位以上です 。
・各年次に1年以上、通算4年以上在学することが必要です 。
・卒業に必要な単位数や科目の詳細は、教育課程表で確認してください 。
(3) 留年
・進級要件を満たせない場合、または在学年限を超えた場合は留年となります 。
・留年しても、在学年限内であれば、卒業要件を満たした時点で卒業できます 。
・留年した場合、授業料等はその学期の定められた額を納入する必要があります 。
(4) 早期卒業制度
・学部を3年で卒業できる制度です 。
・成績が特に優秀で、卒業に必要な単位を修得し、かつその他の卒業要件を満たした場合、教務委員会の審議を経て卒業が認められます 。
・大学院進学を強く希望している学生が対象となります 。
・申請方法など詳細は、各学期始めにL-Camで通知されます 。
